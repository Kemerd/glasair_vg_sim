### Speed/Re convention and the Re = 6M Mach note

All 2D validation cases use chord c = 1.0 m and set U = Re * nu / c with nu
from `aircraft.yaml`. At Re = 6e6 this gives U ~ 87.6 m/s, i.e. M ~ 0.26 --
**above** the M < 0.2 quasi-incompressible guideline. The decision, recorded
here deliberately: **keep c = 1.0 m and run Re 6M anyway as a trend point**,
rather than scaling the chord. Rationale:

* The validation gate (Cl-alpha slope, Clmax, stall AoA, transition location)
  is anchored at Re = 3M where M ~ 0.13; Re 6M extends the Re trend only.
* An incompressible solve at M 0.26 shifts absolute lift-curve slope by
  roughly Prandtl-Glauert 1/sqrt(1 - M^2) ~ +3.5% -- visible, but this
  project's standing rule is **trust deltas, not absolutes**, and every
  configuration comparison happens at matched conditions where the bias
  cancels.
* Keeping one chord keeps ONE mesh family and one first-cell-height chain
  for the whole Re sweep, which is worth more to the comparisons than a
  cosmetic Mach number; this matches common practice for simpleFoam airfoil
  polar studies.

### Blunt trailing edge

The mesh keeps the REAL measured LS(1)-0413 trailing-edge base (0.0055 c
open gap, from the committed UIUC coordinate set) instead of closing it.
This is a transition study: the actual TE thickness influences the aft
pressure recovery and therefore the upper-surface transition/separation
behaviour the gate measures. The XFOIL anchor runs a sharp-TE closure (XFOIL
requires it); RANS keeps the as-built geometry. The comparison philosophy is
again *trust deltas*: XFOIL-vs-RANS absolute offsets attributable to the TE
treatment are constant across the polar and cancel in slopes and increments.

## Mesh

Structured 5-block C-grid (blockMesh), far field 25 c in every direction,
wake block to 25 c downstream of the TE, one cell thick in z with `empty`
front/back patches. Surface resolved by spline edges through the resampled
241-point loop. First wall-normal cell from `scripts/first_cell_height.py`
(Schlichting flat-plate chain, y+ = 1 target), growth ratio <= 1.2, >= 30
cells inside the estimated boundary layer.

```

first wall cell      : 8.4519e-06 m (correlation y1 = 8.4519e-06 m / sqrt(2)^0)
wall-normal run      : 73 cells, ratio 1.1997 (cap 1.2), grading 492287.6
BL layer budget      : 34 cells inside d99 = 18.74 mm (spec floor 30)
surface cells/side   : 128  zones [44/46/38], d_LE = 1.15e-03 m, d_TE = 2.63e-03 m, max zone ratio 1.0550
wake run             : 42 cells, ratio 1.1964, grading 1560.0, first = TE spacing
blunt-TE base        : 6 uniform cells across 0.0055c
total cells          : 25072
```

Refinement `--level {0,1,2}` multiplies every direction's count by sqrt(2)
per level and shrinks the first cell by the same factor (true uniform
refinement for the spec section 4 GCI study).

Known, accepted compromise: the blunt-base wall (the 0.0055 c vertical face
at the TE) is resolved by the wake block's streamwise spacing, not by a
y+ < 1 cell. The base sits in dead-air recirculation where u_tau is tiny, so
its y+ stays low in practice; the yPlus function object writes the evidence
and the gate script will flag it if the assumption fails.

## Running (WSL2 Ubuntu, ESI OpenFOAM v2506)

```
./Allrun          # blockMesh -> checkMesh -> decomposePar -> simpleFoam (8 ranks) -> reconstructPar
```

`Allrun` sources `/usr/lib/openfoam/openfoam2506/etc/bashrc` if no OpenFOAM
environment is active, and exits with a clear message when the toolkit is
not installed (dry-run friendly: the case directory itself is complete and
valid without OpenFOAM present).

Convergence gate (spec section 4): all initial residuals < 1e-5 (the
`residuals` function object writes the history; `fvSolution` stops the run
below that with margin) AND Cl/Cd flat to < 0.5% over the last 500
iterations (from `postProcessing/forceCoeffs1`).

## Post-stall fallback: simpleFoam -> pimpleFoam pseudo-transient

High-AoA points past stall can refuse to converge steady (shedding wants to
exist). Per spec Phase-1 item 3 the documented fallback is pimpleFoam with
LOCAL-EULER pseudo-transient stepping. Exact dictionary deltas -- apply
these and nothing else, then rerun:

1. `system/controlDict`
   * `application simpleFoam;` -> `application pimpleFoam;`
   * keep `deltaT 1;` -- under localEuler the global time index is just an
     outer-iteration counter; `endTime` stays an iteration budget.
2. `system/fvSchemes`
   * `ddtSchemes { default steadyState; }` -> `ddtSchemes { default localEuler; }`
3. `system/fvSolution` -- add final-iteration solver entries and a PIMPLE
   block (relaxation factors stay as-is; pimpleFoam reads them for outer
   correctors):

   ```
   solvers
   {
       "(p)Final"        { $p;  relTol 0; }
       "(U|k|omega|gammaInt|ReThetat)Final" { $U; relTol 0; }
   }
   PIMPLE
   {
       nOuterCorrectors         2;
       nCorrectors              1;
       nNonOrthogonalCorrectors 1;
       // Pseudo-time ramp control for localEuler:
       maxCo                    5;
       rDeltaTSmoothingCoeff    0.05;
       rDeltaTDampingCoeff      0.5;
       maxDeltaT                1;
   }
   ```
4. Convergence is then judged on the SAME force-flatness criterion (< 0.5%
   over the trailing window); residual levels under LTS are not comparable
   to the steady gate and are recorded but not gated.

A fallback run must be flagged in the validation report as pseudo-transient
(the gate script reads `application` from controlDict).
